# 📝 ToDo List - Projeto de Estudos

Este é um projeto de Lista de Tarefas (ToDo List) desenvolvido para rodar localmente. Ele foi criado como parte do meu processo de aprendizagem e evolução contínua no desenvolvimento de software.

# 🎯 Objetivo do Projeto

O foco principal deste repositório não é ser uma aplicação comercial para o usuário final, mas sim um ambiente de estudos. Através deste projeto, busco:

Praticar lógica de programação;

Compreender o funcionamento do ambiente de execução do JavaScript fora do navegador;

Consolidar conhecimentos básicos e intermediários de estruturação de código;

Registrar minha evolução técnica no GitHub.

# ✨ Funcionalidades

Adicionar tarefas: Inserir novos itens na lista.

Listar tarefas: Visualizar as atividades pendentes.

Concluir/Remover tarefas: Gerenciar o ciclo de vida de cada atividade.

# 🛠 Tecnologias Utilizadas

Node.js - Ambiente de execução JavaScript (Runtime).

JavaScript - Linguagem de programação.

# 🚀 Como Executar Localmente

Siga os passos abaixo para rodar o projeto na sua máquina:

Pré-requisitos

Você precisará ter o Node.js e o Git instalados no seu computador.

Instalação e Execução

Faça o clone deste repositório:

git clone https://github.com/Floriano-Back/ToDo_List.git


Navegue até o diretório do projeto:

cd ToDo_List


Instale as dependências (caso o projeto possua um arquivo package.json):

npm install


Execute a aplicação:

node index.js 


(Caso o arquivo principal do seu projeto tenha outro nome, como app.js ou server.js, substitua index.js pelo nome correto).
